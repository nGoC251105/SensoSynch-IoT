SENSOSYNCH V12 · ESP32 · MQTT · Node.js · MySQL

API Documentation

Danh sách endpoint phục vụ Dashboard, Data Sensor, Action History và điều khiển LED.

Base URL: http://localhost:3000

Danh sách API

Ví dụ điều khiển LED

POST http://localhost:3000/api/devices/1/control
Content-Type: application/json

{"action":"ON"}
Phản hồi: Hệ thống tiếp nhận lệnh, trả ID và trạng thái lệnh. Kiểm tra tiếp GET /api/actions/{id} để xác nhận SUCCESS hay FAILED. Trường hợp ESP32 offline có thể ghi hành động FAILED vào Action History.

Kiểm thử

Chạy backend trước khi dùng Postman. Các URL bắt đầu bằng /api/ (không có /api/v1/). Mã phản hồi có thể gặp: 200, 202, 400, 404, 409, 503.

Tài liệu đi kèm mã nguồn của phiên bản SENSOSYNCH đang được cấu hình; không phải tài liệu Swagger tự sinh.
