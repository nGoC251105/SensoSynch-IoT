# Giao diện SENSOSYNCH V12

Đây là giao diện V12 đã pass, giữ nguyên HTML/CSS. JS đã chuyển từ mô phỏng sang REST API và MQTT thông qua backend.

**Hướng dẫn chạy thực tế:** xem `../README_BAT_DAU.md`.

Không mở index.html bằng `file://`; chạy `cd backend && npm start` rồi truy cập http://localhost:3000.
